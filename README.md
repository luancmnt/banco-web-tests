# Banco Web Tests

This project contains automated web tests for the Banco Web application using Cypress and JavaScript.

## Purpose

The main goal of this project is to automate the web part of the Banco Web system. The tests validate common user actions such as login and money transfers in the browser, helping to keep the application stable and reliable.

## Project components

The project is organized as follows:

- Cypress tests:
  - [cypress/e2e/login.cy.js](cypress/e2e/login.cy.js) - login scenarios
  - [cypress/e2e/transfers.cy.js](cypress/e2e/transfers.cy.js) - transfer scenarios
- Custom commands:
  - [cypress/support/commands/login.js](cypress/support/commands/login.js) - login commands
  - [cypress/support/commands/common.js](cypress/support/commands/common.js) - shared commands
  - [cypress/support/commands/transfers.js](cypress/support/commands/transfers.js) - transfer-related commands
- Fixtures:
  - [cypress/fixtures/credentials.json](cypress/fixtures/credentials.json) - test user data
- Configuration:
  - [cypress.config.js](cypress.config.js) - Cypress configuration and report setup
- Reports:
  - [cypress/reports/html](cypress/reports/html) - HTML reports generated by Cypress Mochawesome

## Requirements

Before running the tests, make sure these projects are running:

- API: https://github.com/juliodelimas/banco-api
- Web application: https://github.com/juliodelimas/banco-web

The web app should be available at:

- http://localhost:4000

## Installation

1. Clone this repository.
2. Open the project folder.
3. Install the dependencies:

```bash
npm install
```

This project uses the dependencies listed in [package.json](package.json), including:

- Cypress
- cypress-mochawesome-reporter

## Running the tests

### Run tests in headless mode

```bash
npm test
```

### Run tests in headed mode

```bash
npm run cy:headed
```

### Open the Cypress interface

```bash
npm run cy:open
```

## Test coverage

### Login tests

The login suite checks:

- login with valid data
- login with invalid data

### Transfer tests

The transfer suite checks:

- a valid transfer flow using origin and destination accounts
- success feedback shown to the user

## Custom commands

This project uses Cypress Custom Commands to keep the tests cleaner and easier to maintain.

### Available commands

- `loginWithValidData()`
  - fills in valid login credentials and submits the form
- `loginWithInvalidData()`
  - fills in invalid login credentials and submits the form
- `checkToastMessage(message)`
  - verifies that a toast message appears with the expected text

These commands are defined in the support folder and are reused by the test files.

## Reports

Test reports are generated with Cypress Mochawesome Reporter.

After execution, an HTML report is available in:

- [cypress/reports/html](cypress/reports/html)

You can open the generated report in your browser from that folder.

## Notes

- The tests depend on the web app being running locally.
- The base URL is configured in [cypress.config.js](cypress.config.js).
- If you want to add more scenarios, it is a good practice to keep the test logic in the spec files and reuse actions through custom commands.
